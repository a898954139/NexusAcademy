Nexus Media Automation

YouTube Data API integration

An internal, owner-operated publishing workflow for original Nexus trading-education videos and YouTube Shorts.

Operator: Chan Wei Feng Channel: Ryan | Nexus Updated: 27 July 2026
Internal access only

The client is not offered to the public and has no public registration or demo account.

Original content only

It uploads media created or commissioned by Nexus for a channel controlled by the operator.

Approval before publishing

Assets, titles and descriptions pass through the Nexus approval workflow before upload.

Purpose

What the API client does

Nexus Media Automation prepares and delivers approved educational videos to the owned Ryan | Nexus YouTube channel. The client applies the approved title, description, educational disclaimer and privacy setting, uploads the media, and reads the resulting YouTube record back to verify delivery.

The tool does not search for, download, copy, re-host or monetise third-party YouTube content. It does not provide public YouTube browsing, analytics or account-management services.

Workflow

Controlled publishing flow

1. Approval

Ryan approves the final media package and publishing metadata.

2. OAuth upload

The authorised owner account uploads the approved asset through the API.

3. Readback

The workflow verifies the channel identity and delivered video metadata.

Publishing fails closed when approval, asset validation, channel identity or API readback checks do not pass.

Methods

YouTube Data API methods

  • youtube.channels.list verifies the authorised channel identity.
  • youtube.videos.insert uploads approved original videos and their metadata.
  • youtube.videos.list verifies processing state, visibility and delivery metadata.

OAuth access is restricted to the channel owner. Credentials are stored locally and are never included in public evidence, source control or approval messages.

Controls

Privacy, revocation and deletion

Google authorisation can be revoked from the operator's Google Account connections. A verified deletion request may also be sent to mynexustrading@gmail.com.
